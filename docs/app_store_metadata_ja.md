## 概要

Dr's Salaryは、医師の給与・収入をまとめて管理できるアプリです。

常勤先の給与だけでなく、外勤、スポット勤務、賞与など、複数の勤務先から得られる収入をまとめて記録できます。

給与明細のOCR読み取りにも対応。カメラで撮影した給与明細、写真ライブラリの画像、PDFから内容を読み取り、給与入力をサポートします。読み取り結果は入力フォームで確認・修正してから保存できるため、原本と照らし合わせながら記録できます。

総支給額、手取り、控除合計、所得税、住民税、勤務先ごとの控除項目などを記録し、月別・年別の推移や勤務先別、収入区分別の内訳を確認できます。

給与明細、源泉徴収票、支払調書などのPDFや画像も端末内に保存できるため、年末調整や確定申告前の書類整理にも役立ちます。

主な機能
・給与明細の写真、画像、PDFを端末内OCRで読み取り
・読み取り結果を確認、修正して給与明細へ保存
・勤務先ごとの給与管理
・総支給額、手取り、控除の記録
・月別、年別の収入推移グラフ
・勤務先別、収入区分別の内訳分析
・勤務先ごとの控除項目設定
・給与明細、源泉徴収票、支払調書などの書類管理
・CSV出力
・Face ID / Touch IDによるアプリロック

給与情報、添付ファイル、OCRで認識した内容は端末内で処理・保存され、外部のOCRサービスや開発者のサーバーへ送信されません。ログインやクラウド同期もありません。

本アプリは、収入記録と書類整理の補助ツールです。税務計算、確定申告書作成、税務助言、申告代行を行うものではありません。登録内容や集計結果はユーザーご自身で確認し、税務判断が必要な場合は税理士、税務署などの専門窓口へご相談ください。

## App Review Notes

本アプリはログイン不要で利用でき、レビュー用アカウントは必要ありません。

給与明細のOCR読み取りは、ホーム画面上部の「今月の記録を取り込む」、または給与明細追加画面の取込ボタンから利用できます。カメラ撮影、写真ライブラリの画像、PDFのいずれかを選ぶと端末内でOCR処理が行われ、認識できた支給年月、勤務先、総支給額、手取り、控除合計、所得税、住民税、勤務先固有の控除項目が給与明細入力フォームへ反映されます。結果を確認・修正し、画面右上の保存操作で登録します。OCR結果が自動保存されることはありません。

OCRにはApple VisionおよびPDFKitを使用しています。給与明細画像、PDF、認識テキスト、給与情報を外部サーバーや第三者のOCRサービスへ送信しません。元画像またはPDFを添付した場合のみ、端末内のアプリ領域へ保存します。

Face ID / Touch IDロックは任意機能で、設定画面から有効化できます。認証にはAppleのLocalAuthenticationを使用し、生体情報をアプリが取得・保存することはありません。

CSV出力はユーザー操作によって共有シートを開く機能で、自動送信は行いません。

本アプリは収入記録と書類整理の補助ツールであり、税務計算、確定申告書作成、税務助言、申告代行は行いません。
